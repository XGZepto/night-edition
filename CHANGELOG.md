# Changelog

## 1.0.0 — 2026-11-09

First public release.

- Feature images letterboxed at 2.39:1, with portrait images pillarboxed
- Captions set as subtitles, with film grain over photos
- A home-page title card that fills one line of the screen
- Numbered scenes for headings and an end card on every story
- Full-screen search, subscribe and sign-in, typed like subtitles
- Bilingual 中文 / English posts with per-language reading time
- A full-screen menu on phones
- Subscribe follows the site's membership settings: the theme's form for free signup; Ghost's Portal for paid tiers, required terms or paid-only signup; Sign in only on invite-only sites
- Ghost cards use the theme's type; video embeds scale to the column
- Layouts for sites without a logo, cover image or description
- Animation respects reduced-motion settings; dialogs work from the keyboard and return focus when closed
